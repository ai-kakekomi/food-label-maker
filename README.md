# 食品表示ラベルメーカー（food-label-maker）

加工食品（一般用）の**一括表示**と**栄養成分表示**を入力し、食品表示基準にもとづくチェックを受けて、ラベル案を作るための無料Webツールです。

非営利団体 **AIかけこみ寺** が制作し、**MITライセンス** で公開しています。

---

## ⚠ はじめに必ずお読みください

> **本ツールは参考情報です。表示内容の最終確認は必ず食品表示基準および消費者庁の最新ガイドラインで行ってください。**

- 本ツールは**無保証**です。制作者・提供者は、本ツールの利用によって生じたいかなる損害についても責任を負いません。
- 本ツールが出力するのは**下書き**です。実際に販売する商品の表示は、必ず表示の責任者（食品関連事業者）が最終確認してください。
- **ルールはまだ専門家の監修を受けていません。**すべてのルールに「未監修」バッジが付いています（下記「監修状況」参照）。

### 対応している範囲

| | |
|---|---|
| 対応 | 加工食品（一般用・容器包装に入れられたもの）の一括表示 |
| 対応 | 栄養成分表示（義務5項目：熱量・たんぱく質・脂質・炭水化物・食塩相当量）の入力とチェック |
| **非対応** | 栄養成分の値そのものの計算・分析・丸め規則、許容差の範囲の判定 |
| **非対応** | ビタミン・ミネラル等の任意表示成分、栄養強調表示（「低カロリー」「減塩」など）の基準値判定 |
| **非対応** | 生鮮食品、業務用食品、酒類、外食、添加物そのものの表示 |
| **非対応** | 別表第4・別表第15の1などの個別品目の特例（一部は「人の確認が必要」として提示するのみ） |
| **非対応** | 保健機能食品（特定保健用食品・機能性表示食品・栄養機能食品）の表示 |

## 動かし方

このツールは**完全な静的サイト**です。サーバーもデータベースも使いません。入力した内容は**あなたのブラウザの中（localStorage）だけ**に保存され、インターネットには一切送信されません。

### ブラウザで開く

ルールファイル（YAML）を読み込む都合上、**HTMLファイルを直接ダブルクリックして開く（`file://`）と動きません**。かんたんなローカルサーバーを立てて開いてください。

**Windows（PowerShell）で Python を使う場合：**

```powershell
cd food-label-maker
python -m http.server 8000
```

**Node.js を使う場合：**

```powershell
cd food-label-maker
npx --yes http-server -p 8000
```

そのあとブラウザで <http://localhost:8000/> を開きます。

対応ブラウザ：PC の Chrome / Edge 最新版。

### 使う流れ

1. 画面上の「サンプル1 クッキー」ボタンを押して、動きを確かめる
2. 自分の商品の内容に書き換える
3. 「この内容を検証する」を押す
4. **要修正（error）** をすべて直す
5. **人の確認が必要** の項目を1つずつ確認してチェックを入れる
6. ラベル案をコピー、または印刷する
7. **最後に必ず人の目で確認する**

## 画面の説明

| 画面 | 内容 |
|---|---|
| `index.html` | 入力フォーム・検証結果・ラベル案（一括表示枠＋栄養成分表示） |
| `manual.html` | **使い方マニュアル**。はじめての方向けの操作手順、アレルゲン入力の考え方、ルールの直し方を画面上で読めます。各ページのナビから1クリックで開けます |
| `rules.html` | **監査モード**。このツールが使っている全ルールを、根拠条文・出典URL・最終確認日つきで一覧表示します。専門家のレビュー用です |

**操作方法がわからないときは、まず [`manual.html`](manual.html) を開いてください。**このREADMEより平易に、画面つきで説明しています。

### 検証結果の4段階

| 表示 | 意味 |
|---|---|
| **要修正**（error） | 法令違反のおそれがあります。直してください |
| **要確認**（warn） | 推奨事項・慣行です。確認してください |
| **人の確認が必要**（check） | 機械では判定できない項目です。チェックリストとして提示します（例：原材料が本当に重量順か） |
| **問題なし**（pass） | このルールについては問題が見つかりませんでした |

「問題なし」でも、それは**このツールに入っているルールの範囲で**問題が見つからなかったという意味にすぎません。

## ルールの直し方（プログラムの知識は不要です）

このツールの一番の特徴は、**検証ルールがプログラムの中ではなく、日本語のYAMLファイルに書かれている**ことです。法令が変わったら、YAMLファイルを直すだけで対応できます。現在、法令ルールは**60本**です。

### ファイルの場所

```
rules/
  index.json                 ← 読み込むファイルの一覧
  base/                      ← 法令由来のルール（全社共通）
    00_アレルゲン辞書.yaml     ← 特定原材料等の品目・代替表記のデータ
    01_名称.yaml
    02_原材料名.yaml
    03_添加物.yaml
    04_アレルゲン.yaml
    05_内容量・期限・保存.yaml
    06_事業者・様式.yaml
    07_栄養成分.yaml
  custom/                    ← 各社の社内ルール
    sample.yaml              ← 社内ルールのテンプレート
```

YAMLファイルは**ただのテキストファイル**です。メモ帳やVS Codeなど、好きなエディタで開けます。

### ルール1本の書き方

```yaml
  - id: allergen-mandatory-8            # ルールを見分けるための名前（英数字。重複しないこと）
    名称: 特定原材料8品目の表示義務        # 画面に出る、ルールの名前
    根拠: 食品表示基準 別表第14／…        # 何の条文にもとづくか
    出典URL: https://www.caa.go.jp/…     # 一次情報のURL（消費者庁のページ）
    最終確認日: ""                       # 一次情報と突き合わせて確認した日。空欄なら「未監修」
    条件: 原材料に特定原材料を含むとき     # どんなときに適用されるか（人が読むための説明）
    判定: その特定原材料を含む旨が表示されていること
    重大度: error                        # error＝法令違反のおそれ ／ warn＝推奨・慣行
    メッセージ: 「{品目}」は特定原材料です。表示が見当たりません。
    ヒント: |
      画面に出す補足説明。複数行書けます。
    機械判定:                            # ここだけプログラム向けの指定
      種別: アレルゲン表示
      対象範囲: 特定原材料
```

### 直し方：コピペできるプロンプトをAIに渡す

**書き方を覚える必要はありません。** 下の文をそのまま **Claude Code などのAIコーディングエージェント** に貼り付けてください。
ソースの入手（初回）も更新（2回目以降）も、AIがやってくれます。

```
「食品表示ラベルメーカー」というオープンソースのツールを、自分用に手直ししたいです。
まず、ソースを手元に用意してください。

- 置き場所: https://github.com/ai-kakekomi/food-label-maker
- 手元にまだ無ければ、作業用フォルダに git clone してください
- すでに手元にあれば、git pull で最新に更新してください（私が加えた変更は消さないでください）
- 用意できたら中身をひととおり読んで、このツールが何をするものか、
  チェックのルールがどのファイルに書いてあるかを、日本語でかんたんに教えてください
- 最後に、ローカルサーバー（例: python3 -m http.server 8000）で開いて、
  画面がちゃんと表示されることを確認してください
```

そのあとは、やりたいことを日本語で頼むだけです。どのファイルを直せばよいかはAIが自分で探します。

- 「期限の日付書式のルールのメッセージを、もっとやさしい言葉に変えて」
- 「すべてのルールの『最終確認日』に 2026/9/1 を入れて。未監修バッジを外したい」
- 「アレルゲンのルールの根拠と出典URLを新しいものに直して」
- 「アレルゲンの品目に『カシューナッツバター』という書き方を追加して」
- 「『○○』というルールは、うちの商品には合わないので止めて」
- 「冷凍食品向けに、凍結前加熱の有無を確認させるチェックを追加して」
- 「検証結果をExcelに貼れる形で書き出せるようにして」

おかしくなったら「さっきの変更を全部取り消して」と頼めば戻ります。

詳しい手順は [`manual.html` の7章](manual.html#ask-ai) にあります。

### 「機械判定」に使える種別

| 種別 | 何をするか |
|---|---|
| `必須項目` | 指定した欄が空でないことを確認する |
| `正規表現一致必須` | 指定した欄が、指定した文字パターンを含むことを確認する |
| `正規表現禁止` | 指定した欄に、指定した文字パターンが含まれないことを確認する |
| `数値下限` | 指定した欄の数値が下限以上であることを確認する |
| `確認事項` | **機械では判定せず**、人が確認するチェックリストとして画面に出す |
| `栄養成分5項目` ほか | 栄養成分表示の専用判定（欠落・順序・単位・ナトリウム表記など） |
| `用途名併記` ほか | アレルゲン・添加物などの専用判定（法令ルール用） |

機械で判定するのが難しいもの（例：「原材料が本当に重量順に並んでいるか」「名称が一般的な名称か」）は、無理に自動判定せず `確認事項` にしています。**分からないことを分かったふりで判定しない**のが、このツールの方針です。

## 社内ルールを追加する

各社の社内規程・慣行を、法令ルールと同じ仕組みでチェックできます。**ファイルを自分で書く必要はありません。**

1. 上のプロンプトでソースをAIに渡す
2. 社内ルールを日本語で説明して、「読み込める形の社内ルールのファイルを作って」と頼む
   （AIは `rules/custom/sample.yaml` を参考にします）
3. 画面の「10. 社内ルールの読み込み」で、作ってもらったファイルを選ぶ

読み込んだ社内ルールは、画面上で**「社内ルール」バッジ**が付き、法令ルールと区別されます。
読み込んだファイルもインターネットには送信されません。読み込みエラーが出たら、そのままAIに伝えれば直してくれます。

```
food-label-maker/
  index.html          入力フォーム・検証結果・ラベル案
  manual.html         使い方マニュアル（非エンジニア向け）
  rules.html          ルール一覧（監査モード）
  css/
    style.css         画面用スタイル
    print.css         印刷用スタイル
  js/
    rules.js          ルールYAMLの読み込み
    engine.js         判定エンジン
    label.js          一括表示枠・栄養成分表示枠の組み立て
    samples.js        デモ用サンプルデータ
    app.js            画面まわり
    rules-page.js     ルール一覧ページ
  rules/              ← ここを直せばルールが変わります
  vendor/
    js-yaml.min.js    YAML読み込みライブラリ（MITライセンス／同梱）
  test/
    test.js           ルールYAMLと判定エンジンの自動テスト（依存なし）

  README.md
  LICENSE
```

外部のCDNは一切参照していません。すべてのファイルがこのフォルダに入っています。

### テストの実行

Node.js がある環境で、YAMLの文法とエンジンの動作を確認できます。**外部パッケージは不要です。**

```powershell
node test/test.js
```

画面まわりの回帰テストもあります。こちらは `jsdom` が必要で、入っていない場合は自動でスキップされます
（テスト用の静的サーバーはスクリプトの中で立てるので、別途 python 等は不要です）。

```powershell
npm install jsdom
node test/ui-test.js
```

`jsdom` はテスト専用です。**ツール本体は依存パッケージなしで動きます。**
