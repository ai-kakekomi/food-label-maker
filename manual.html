1. このツールでできること・できないこと

加工食品（一般用）の一括表示、つまりパッケージの裏に付いている 「名称・原材料名・添加物・内容量・賞味期限…」の四角い枠を作るためのツールです。

できること

  • 一括表示の各項目を、順番に入力できる
  • 食品表示基準にもとづく50本のルールで自動チェックできる
  • 指摘ごとに根拠の条文と消費者庁のページへのリンクが出る
  • 一括表示枠のラベル案を作って、コピー・印刷できる
  • 自社の社内ルールを追加できる

できないこと（対象外）

  • 栄養成分表示の計算・丸め
  • 生鮮食品、業務用食品、酒類、外食の表示
  • 個別品目の特例（別表第4・別表第15の1など）の細かい判定
  • 特定保健用食品・機能性表示食品の表示
  • 「これで法令に適合している」という保証

このツールが出すのは下書きです。 最後は必ず人の目で、食品表示基準と消費者庁の最新ガイドラインを見て確認してください。

2. まずはサンプルで試してみる

いきなり自分の商品を入力するより、先にサンプルを入れて動きを見るほうが早く分かります。

ラベル作成の画面をひらく

画面のいちばん上に、サンプルのボタンが2つあります。

サンプル1 クッキー
ひととおり正しく入力されている「お手本」です。検証すると要修正が0件になります。
サンプル2 くるみパン
よくある間違いをわざと入れてあります。検証すると 「くるみの表示漏れ」「卵黄に（卵を含む）がない」「保存料の物質名がない」などが指摘されます。 どんな指摘が出るのかを見るのに便利です。

サンプルを押すと、いま入力している内容は置きかわります。 入力内容はブラウザに自動保存されるので、次に開いたときは続きから作業できます。

3. 操作の手順

  1. 入力する

    画面の左側を、上から順に埋めていきます。必須 が付いている欄は必ず入力してください。

    • 名称…商品名やブランド名ではなく、中身を表す一般的な名称（例：焼き菓子（クッキー））
    • 原材料名…重量の多い順に1つずつ追加します。「＋ 原材料を追加」ボタンで行が増えます
    • 添加物…添加物の中で重量の多い順に入力します
    • 内容量・期限・保存方法・事業者…そのまま埋めていきます

    入力欄には「印刷される文字そのもの」を書いてください。
    たとえば マーガリン（乳成分を含む） のように、カッコの中まで含めて書きます。 原材料の行は「↑」「↓」ボタンで並べ替え、「×」で削除できます。

  2. 検証する

    右側の 「この内容を検証する」 ボタンを押します。50本のルールで一斉にチェックされます。

    結果は右側に一覧で出ます。1件ずつ開くと、指摘の内容・ヒント・根拠の条文と出典リンクが読めます。

  3. 直して、また検証する

    要修正（赤）をゼロにするのが目標です。直したらもう一度「この内容を検証する」を押します。
    「人の確認が必要（青）」の項目は、内容を読んで確認できたら 「確認しました」にチェックを入れてください。チェックすると件数が減ります。

  4. ラベル案を受け取る

    右側の上にある「ラベル案（一括表示枠）」に、一括表示の枠が表示されます。 入力を変えるとすぐに反映されます。

    • テキストをコピー…文字だけをコピーします。メールやWordに貼り付けられます
    • 印刷する…ラベル案だけを紙に印刷します（入力フォームや検証結果は印刷されません）

  5. 最後に人が確認する

    ここがいちばん大事です。このツールが「問題なし」と言っても、それは このツールに入っている50本のルールの範囲で問題が見つからなかった、という意味にすぎません。 版下にする前に、必ず表示の責任者が食品表示基準で最終確認してください。

4. 検証結果の読み方

結果は4つに色分けされます。

表示意味どうすればよいか
要修正 法令違反のおそれがあります 必ず直してください。0件になるまで直します
要確認 推奨事項や、業界の慣行です 内容を読んで、自社の商品に当てはまるか確認します
人の確認が必要 機械では判定できない項目です。
（例：原材料が本当に重量順に並んでいるか） 		配合表などと見比べて確認し、「確認しました」にチェックを入れます
問題なし このルールでは問題が見つかりませんでした とくに作業はいりません

「未監修」バッジについて

ほとんどの指摘に 未監修 というバッジが付いています。 これは そのルールがまだ食品表示の専門家のレビューを受けていない という意味です。 ルールの内容が正しいかどうかは、必ず出典リンク先の消費者庁の資料でご確認ください。

専門家のレビューが済んだルールには「最終確認日」が入り、このバッジは消えます。 レビューにご協力いただける方を募集しています（info@ai-kakekomi.com）。

5. アレルゲンの入力のしかた

表示漏れがいちばん重大な事故につながるところです。ここだけは丁寧に読んでください。

入力するのは「2つ」です

原材料の行には、次の2つを別々に入力します。この2つを突き合わせることで、表示漏れを見つけます。

入力するもの意味例
表示名（上の文字入力欄） 実際にパッケージに印刷される文字そのもの マーガリン（乳成分を含む）
アレルゲン（下のチェックボックス） その原材料に本当に入っているもの（表示するかどうかとは別） 「乳」にチェック

「アレルゲン：なし（クリックして選ぶ）」の部分をクリックすると、28品目のチェックボックスが開きます。 赤い枠の8品目が表示義務のある特定原材料、その下の20品目が表示が推奨されている品目です。

よくある間違いと、このツールの動き

アレルゲンにチェックしたのに、表示名に書いていない
要修正 になります。これが「表示漏れ」です。
表示名が代替表記になっている（例：小麦粉）
問題なしになります。小麦粉 は「小麦」の代替表記なので、 あらためて「（小麦を含む）」と書かなくてよいことになっています。
表示名に「卵白」「卵黄」と書いてある
要修正 になります。「卵」の字が入っていますが、 事故防止の観点から省略は認められていないため、卵黄（卵を含む） と書く必要があります。
「乳を含む」と書いた
要修正 になります。原材料では 乳成分を含む、 添加物では 乳由来 と書きます（添加物だけ「乳成分由来」ではないので注意）。
表示名にアレルゲンの名前が入っているのに、チェックを忘れている
要確認 でお知らせします（例：ごま油 なのに「ごま」未チェック）。 入力ミスを見つけるための補助チェックです。

個別表示と一括表示

アレルゲンの書き方は2通りあり、混ぜて使うことはできません。

方式書き方注意
個別表示
（このツールの初期設定）		 原材料ごとに （○○を含む） を付ける 同じアレルゲンが何度も出るときは、1回書けば残りは省略できます
一括表示 最後にまとめて （一部に○○・△△を含む） と書く 省略できません。小麦粉 のように名前から分かるものも 含めて全部書き出す必要があります

一括表示を選ぶと入力欄が出ます。品目名を「・」でつないで入力してください（例：小麦・卵・乳成分・大豆）。 前後の「（一部に」「を含む）」は自動で付きます。

6. ルールの直し方

このツールの一番の特徴です。 チェックのルールは、プログラムの中ではなく日本語で書かれたファイルに入っています。 法令が変わったら、そのファイルを直すだけで対応できます。プログラムの知識は要りません。

ルールのファイルはどこにあるか

ツールのフォルダの中の rules フォルダです。

rules/
  index.json                 ← 読み込むファイルの一覧
  base/                      ← 法令のルール（全社共通）
    00_アレルゲン辞書.yaml      ← 特定原材料等の品目・代替表記のデータ
    01_名称.yaml
    02_原材料名.yaml
    03_添加物.yaml
    04_アレルゲン.yaml
    05_内容量・期限・保存.yaml
    06_事業者・様式.yaml
  custom/                    ← 各社の社内ルール
    sample.yaml              ← 社内ルールのテンプレート

.yaml という拡張子のファイルは、ただの文字のファイルです。 メモ帳でも開けます（文字化けする場合はVS Codeなどのエディタをお使いください）。

いちばんかんたんな直し方：AIに頼む

自分で書き方を覚える必要はありません。 ファイルの中身をまるごとコピーして、ChatGPTやClaudeなどのチャットAIに貼り付け、 日本語で「ここをこう変えて」と頼むのがいちばん簡単です。 返ってきた内容をファイルに上書き保存すれば完了します。

無料版のチャットAIで十分できます。 何かをインストールする必要も、アカウントを作り込む必要もありません。 ブラウザでチャットAIを開くだけです。

  1. ファイルの中身をコピーする

    直したい .yaml ファイルをメモ帳などで開き、 Ctrl＋A（全部選ぶ）→ Ctrl＋C（コピー）します。

  2. チャットAIに貼り付けて、日本語で頼む

    下の「頼みかたの例」のように書いて、コピーした中身を貼り付けます。

  3. 返ってきた全文をファイルに上書き保存する

    AIが返してきた内容を全部コピーして、元のファイルの中身とまるごと入れ替えて保存します。 （メモ帳なら Ctrl＋A で全部選んでから貼り付け）

  4. 画面で確かめる

    ブラウザで再読み込み（Ctrl＋F5）して、 ルール一覧の画面 に反映されているか見ます。

頼みかたの例 ①　文言を変えたい

以下は食品表示チェックツールのルールファイル（YAML）です。
「date-format-within-3months」のルールのメッセージを、
もっとやさしい言葉に変えた全文を返してください。
それ以外の構造や項目は変えないでください。

（ここにファイルの中身を貼り付ける）

頼みかたの例 ②　確認した日付を入れたい

以下は食品表示チェックツールのルールファイル（YAML）です。
すべてのルールの「最終確認日」に "2026/9/1" を入れた全文を返してください。
それ以外は一切変えないでください。

（ここにファイルの中身を貼り付ける）

頼むときのコツは2つだけです。
①「全文を返してください」と書く（一部だけ返されると貼り替えにくいため）
②「それ以外は変えないでください」と書く（余計なところまで直されるのを防ぐため）

失敗しても大丈夫です。 AIの返してきた内容が壊れていると、画面に読み込みエラーが表示されます。 そのときは元のファイルに戻して、もう一度頼めばOKです。 直す前のファイルをコピーして取っておくと、さらに安心です。

ルール1本はこう書かれています

AIに頼む場合は、この書き方を覚える必要はありません。 「どこに何が書いてあるか」を眺めておくと、頼みかたを考えるときに役立ちます。 

  - id: allergen-mandatory-8            # ルールを見分けるための名前（英数字）
    名称: 特定原材料8品目の表示義務        # 画面に出るルールの名前
    根拠: 食品表示基準 別表第14／…        # 何の条文にもとづくか
    出典URL: https://www.caa.go.jp/…     # 消費者庁のページ
    最終確認日: ""                       # 空欄だと「未監修」と表示される
    条件: 原材料に特定原材料を含むとき     # どんなときに使われるか
    判定: その特定原材料を含む旨が表示されていること
    重大度: error                        # error＝要修正 ／ warn＝要確認
    メッセージ: 「{品目}」は特定原材料です。表示が見当たりません。
    ヒント: |
      画面に出す補足説明。何行でも書けます。
    機械判定:                            # ここだけプログラム向けの指定
      種別: アレルゲン表示
      対象範囲: 特定原材料

よくある直しかた

いずれも、上の「AIに頼む」やり方で 「○○を△△に変えた全文を返してください」と書けばそのまま頼めます。 手で直したい方は、そのまま書き換えてください。

① レビューして問題なかったので「未監修」を外したい

最終確認日 に日付を入れるだけです。

    最終確認日: "2026/9/1"

② 法令が変わったので条文名とURLを直したい

根拠 と 出典URL を書き換えて、最終確認日 に今日の日付を入れます。

    根拠: 食品表示基準 別表第14（令和○年改正）
    出典URL: https://www.caa.go.jp/新しいURL
    最終確認日: "2026/9/1"

③ 文章を分かりやすく直したい

メッセージ と ヒント を書き換えるだけです。 チェックの動きは変わりません。いちばん気軽にできる改善です。

④ アレルゲンの品目や書き方（代替表記）を足したい

rules/base/00_アレルゲン辞書.yaml を開いて、リストに行を足します。

  - 品目: カシューナッツ
    代替表記: []
    拡大表記: [カシューナッツバター]

⑤ ルールを1本だけ止めたい

その部分をまるごと消すか、行の先頭に # を付けます（# より後ろは無視されます）。

【補足】自分で手で直したい人向け：書くときの3つの注意

AIに頼んで直す場合は、ここを読まなくても大丈夫です。 自分の手で書き換えたい方だけお読みください。

  1. 行の先頭の空白（インデント）に意味があります。 まわりの行と空白の数をそろえてください。 タブ文字は使えません（スペースを使ってください）。
  2. 文字の中に : や # を入れるときは、" で囲んでください。 例：最終確認日: "2026/9/1"
  3. 保存するときは文字コードを UTF-8 にしてください。 メモ帳なら「名前を付けて保存」の画面の下にある文字コード欄で選べます。

この3つは、慣れないうちはつまずきやすいところです。 間違えても壊れることはありません（画面にエラーが出るだけです）が、 面倒だと感じたら、迷わずAIに頼んでください。

直したあとは、ブラウザで画面を再読み込み（Ctrl＋F5）して、 ルール一覧の画面 に反映されているか確認してください。 書き方を間違えている場合は、画面にエラーの内容が表示されます。 その場合は元のファイルに戻して、もう一度AIに頼み直せば大丈夫です。

7. 社内ルールを追加する

法令のルールとは別に、自社の社内規程や慣行を同じ書き方で追加できます。 追加したルールは画面上で 社内ルール のバッジが付き、 法令のルールとはっきり区別されます。

  1. テンプレートをコピーする

    rules/custom/sample.yaml をコピーして、自社用の名前で保存します（例：まるまる食品_社内ルール.yaml）。

  2. 中身を書き換える

    サンプルには3つの例が入っています。使わない例は消してください。

    ここも 6章の「AIに頼む」やり方 がそのまま使えます。 サンプルの中身をチャットAIに貼り付けて、社内ルールを日本語で説明するだけで、 形を整えた全文を返してくれます。書き方を覚える必要はありません。

    頼みかたの例

    以下は食品表示チェックツールの社内ルールのテンプレート（YAML）です。
これを参考に、次の社内ルールを追加した全文を返してください。
ファイルの形式や構造は変えないでください。

・保存方法の文言は「直射日光、高温多湿を避けて保存してください」に統一する
・「完全無添加」という言葉は使わない
・版下は必ず2人で確認する（これは人が確認する項目にしてください）

（ここにサンプルの中身を貼り付ける）

  3. 画面から読み込む

    ラベル作成の画面の「9. 社内ルールの読み込み」でファイルを選びます。すぐにチェックに反映されます。 読み込みエラーが出たら、書き方が崩れています。 もう一度AIに頼み直せば大丈夫です。

社内ルールで使えるチェックの種類

種別できること使いどころの例
必須項目 指定した欄が空でないことを確認する 「原料原産地名は必ず書く」という社内方針
正規表現一致必須 指定した欄に、決まった言葉が入っていることを確認する 保存方法の文言を社内で統一する
正規表現禁止 指定した欄に、決まった言葉が入っていないことを確認する 「完全無添加」など社内の使用禁止ワード
数値下限 数値が決めた値以上であることを確認する 「文字は法令の8ptより大きく10pt以上にする」という社内基準
確認事項 自動判定はせず、人が確認するチェックリストに出す 「版下は2名でダブルチェックする」という手順

「対象」に指定できる欄の名前の一覧は、rules/custom/sample.yaml のいちばん下に書いてあります。

社内ルールのファイルもこの端末の外には出ません。 配合や社内規程が外部に送信されることはありません。

8. もっとこうしたい、と思ったら

このツールは、コピーも、改造も、配り直すのも自由です。 そして今は、プログラミングの経験がなくても、AIに日本語で頼んで自分で直せる時代になりました。 「もっとこうしたい」と思ったら、開発者に頼むだけでなく、自分で直すという選択肢があります。

2つの「直す」があります

前の章までで説明した内容と合わせると、直しかたは段階的に2つあります。 どちらも「AIに日本語で頼む」という同じやり方です。使う道具が違うだけです。

段階何ができるか使う道具
第一歩
ルール・社内ルールを直す		 チェックの内容や文言を変える、社内ルールを足す
（6章・7章で説明しました） 		無料のチャットAIだけ
（ChatGPT・Claude など）
ファイルを貼り付けて頼む。インストール不要
次の一歩
ツール本体を改造する		 画面の見た目や入力項目を変える、機能を足す、
自社専用のツールに作り変える 		AIコーディングエージェント
（Claude Code・Codex など）
フォルダごと渡して頼む。下で説明します

AIに手伝ってもらって、自分で直す

Claude Code や Codex のような 「AIコーディングエージェント」と呼ばれる道具があります。 フォルダを渡して日本語で「ここをこう変えて」と頼むだけで、 AIがコードを読んで、直して、動かして確かめるところまでやってくれます。 実は、このツール自体もそうやって作られました。

  1. コードを手に入れる

    上のGitHubのページを開いて、緑色の「Code」ボタン →「Download ZIP」を選び、 ダウンロードしたZIPを展開します。これだけで大丈夫です。

    Gitという道具の使い方を知っている方は git clone でも構いません。 知らなくても、まったく問題ありません。

  2. AIコーディングエージェントを用意する

    Claude Code などを入れて、さきほど展開したフォルダを開いた状態で起動します。 導入の手順は道具によって違うので、公式の案内に沿って進めてください。

  3. 日本語で頼む

    専門用語は要りません。やりたいことをそのまま書けば通じます。

    頼みかたの例

    • 「原材料の入力欄に、1行ずつ貼り付けてまとめて登録できるボタンを付けて」
    • 「ラベル案の文字をもっと大きくして、印刷したときに読みやすくして」
    • 「うちは冷凍食品を作っているので、冷凍食品向けのチェック項目を追加して」
    • 「検証結果をExcelに貼れる形で書き出せるようにして」
    • 「会社のロゴと色に合わせて、画面の見た目を変えて」

    うまくいかないときは、何がどう困っているかをそのまま伝えるのがコツです。 「ボタンを押しても何も起きない」「エラーでこう出た」と伝えれば、AIが直してくれます。

  4. 手元で動かして確かめる

    直したら、この下のQ&Aや同梱の README.md の手順で 自分のパソコンで開いて、思ったとおりになっているか確かめます。 おかしくなっても、ZIPをもう一度展開すれば元に戻せます。気軽に試してください。

9. 困ったときは

画面に「ルールファイルを読み込めませんでした」と出る
HTMLファイルを直接ダブルクリックして開くと、ブラウザの制限でルールファイルを読み込めません。 簡易サーバーを立ててから http://localhost:8000/ を開いてください。 手順は同梱の README.md の「動かし方」にあります。
入力した内容が消えてしまった
入力はブラウザに自動保存されますが、 「入力を全部消す」ボタンを押した場合、ブラウザの閲覧履歴・サイトデータを削除した場合、 シークレットウィンドウを閉じた場合は消えます。 大事な内容は「テキストをコピー」で控えを取っておいてください。
ラベル案が思ったとおりの並びにならない
原材料の行の「↑」「↓」ボタンで並べ替えてください。ラベル案は入力した順にそのまま並びます。 原材料と添加物の区切り方（／・改行・別の欄）は「3. 添加物」の 「原材料と添加物の区分方法」で選べます。
印刷すると入力欄まで印刷されてしまう
印刷用の設定で、入力フォームと検証結果は自動的に除かれます。 印刷される内容が違う場合は、ブラウザの印刷画面で「背景のグラフィック」の設定を確認してください。
ルールの内容が間違っている気がする
ぜひ教えてください。各ルールには根拠の条文と出典URLが付いています。 消費者庁の資料と食い違っていたら、GitHubのIssue、または info@ai-kakekomi.com までご連絡ください。 指摘だけでも大変ありがたいです。
